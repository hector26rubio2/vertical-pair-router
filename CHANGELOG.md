# Changelog

Notable changes to Vertical Pair Router are documented here.

## 0.1.1

- Include the README inside the independently copied plugin directory. Native
  lifecycle verification now rejects a missing plugin README.
- Preserve the published 0.1.0 archive and checksums unchanged.

## 0.1.0

- MIT confirmed by the owner with attribution to Vertical Pair Router contributors.
- Installable npm/pnpm archive, self-contained cached Claude plugin, pinned
  runtime lockfile and SBOM; GitHub release pipeline prepared.
- Native `/vpr-use` telemetry and `/vpr-run` workflow command; both previews
  verified without inference. Provider/model/role routing remains local.
- Native Haiku request preflight and context compaction protection, including
  full threaded history and fail-closed handling of unknown counts.
- Technology detection, preserved Husky hooks, staged-secret/configuration
  gate, local Graphify indexing/query and pinned optional Archify installation.
- Bounded corrective execution, project run lock, configurable check deadlines,
  and local graph hints. Provider write permissions are never bypassed.
- Real Finanzas analysis and implementation experiments with common fresh
  review, per-phase token/cost detail, charts and explicit quality limitations.
- Real Codex edits from the CLI and Claude plugin; Finanzas implementation
  trials with separate planning, execution and fresh review. Conditional price
  intervals retain unknown per-request context instead of guessing its tier.
- Copilot SDK 2.0.1 / CLI 1.0.114 integration and account metadata handshake;
  corporate Copilot inference acceptance remains pending.
- Windows/macOS/Linux targets and native lifecycle CI matrix; only executed
  checks count as verified. Windows npm binaries resolve without a command shell.

- Recorded the Phase 0 host audit and base ADRs.
- Added versioned domain contracts and Run lifecycle validation.
- Added safe local process execution, SQLite event persistence, and a vertical
  CLI doctor Run with measured/redacted Evidence.
- Added a minimal Claude Code plugin manifest and verification Skill.
- Added versioned profile previews/applies, protected policy precedence,
  expiring capability evidence, and deterministic shell-free executable
  resolution.
- Added a bounded, privacy-preserving Claude Code `SessionStart` hook with
  host-schema validation and local tests.
- Added nine Spanish VPR workflow Skills, deterministic routing, six eval
  fixtures, and a commit/hash/license audit of the selected AI Hero methods.
- Added the canonical VPR glossary and technical dictionary, Story-linked term
  proposals, validated ADRs, bounded reference-based context packs, SHA-256
  invalidation, stale-source detection, and minimal handoffs.
- Added an event-sourced BacklogService with Story previews, confirmation,
  deduplication and versions; seven vertical planning workflows; validated DAG
  and lifecycle transitions; recovery across SQLite reopen; risk-based human
  review; planning handoffs; and shared CLI Story creation.
- Added typed quality checks, approved-scanner gating, measured TDD records,
  regression-test assessment, full staged/unstaged/untracked diff snapshots,
  dual review policy and snapshot-fresh final verification.
- Added bounded execution budgets, progress-aware cycle detection, idempotent Run
  transitions, event-sourced leases/checkpoints/cancellation/approvals, crash
  resume, exactly-once effect keys and evidence-backed terminal states.
- Added bounded DAG scheduling, hierarchical path locks, recoverable worker/
  integration traceability, single-orchestrator enforcement, conservative
  conflict handling and non-destructive worktree cleanup decisions.
- Added deterministic OmniRouter filtering/ranking and explanation, availability
  evidence gates, opt-in provider fallback, public adapter/SecretResolver
  contracts and credential-safe local/Claude native descriptors.
- Added an observed-only Usage Engine, source-labelled comparisons, local
  authenticated dashboard, shared BacklogService and canonical glossary
  previews/applies, payload allowlisting, JSONL export, retention/deletion,
  non-overwriting SQLite backup, schema/lock checks and CLI controls.
- Separated host adapter descriptors from Core, constrained advertised OS
  support to verified Windows evidence, added sanitized personal/company profile
  examples, a clean-checkout verifier and reversible lifecycle/contribution
  documentation.
- Restricted metric retention to preserve durable Story/Task/Run replay and
  added adversarial shell-argument, HTTP Host/Origin and request-size checks.
