# Security policy

VPR is pre-release software. Do not use it for secrets or production automation
until the relevant phase gate is complete.

Report vulnerabilities privately to the repository owner. Include the VPR
version/commit, Windows and host versions, minimal reproduction, and redacted
logs. Never include API keys, cookies, OAuth/session tokens, private source, or
customer data.

Security-sensitive changes require regression tests, diff review, and current
evidence after the last edit. Publishing, deployment, destructive cleanup,
permission changes, and cross-provider data transmission require explicit
human authorization.
