# ADR-0006: License and release

- Status: BLOCKED
- Date: 2026-11-09

## Proposal

MIT for original code and documentation, with a third-party notice inventory
for every adapted AI Hero file and dependency. Releases use semantic tags,
changelog, SBOM, Windows install/update/rollback/uninstall evidence, and a
public repository only after owner authorization.

## Owner decision required

Only the rights holder can confirm copyright ownership, the final license, and
public publication. Implementation may prepare the files, but it will not
publish or assert that this decision is closed.
